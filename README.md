# Kimra-Quant-Research

个人量化金融文献库，用于长期整理已阅读的学术论文、相关研究资料和个人阅读笔记。

- `papers/` 保存论文元数据、出版社原文、PDF 与相关研究资料链接。
- `notes/` 按论文编号保存独立的阅读笔记。阅读理解、疑问和研究思考由本人记录。

每读完一篇论文，新增一份论文资料和一份对应笔记，并更新下方索引。
